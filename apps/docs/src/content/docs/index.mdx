Yukarıdaki editör **gerçek**: bu sayfada çalışıyor ve yazdığınız her şey
sağda Markdown olarak duruyor. Bir kelime seçin, `/` yazın, `Ctrl+B`'ye
basın — Word'de ne yapıyorsanız.

## Neden Kalem?

Yapay zekâ araçlarının çıktı formatı fiilen Markdown oldu. Ama yazılım
bilmeyen kullanıcıların Word rahatlığında kullanabileceği bir Markdown
editörü yok: ya ham metin yazdırılıyor ya da JSON tutup Markdown'a
"dönüştüren" bir editör veriliyor — ve o dönüşüm kayıplı.

<CardGrid stagger>
  <Card title="Markdown-native" icon="pencil">
    Doğru kaynak her zaman Markdown metnidir, JSON değil.
    `serialize(parse(md)) === md` garantisi sayesinde kullanıcının
    dokunmadığı satır byte düzeyinde değişmez — `*` ile yazdığınız liste
    `-` olarak geri gelmez.
  </Card>
  <Card title="Framework-bağımsız" icon="puzzle">
    Çekirdek saf TypeScript. `@kalem/react` ve `@kalem/vue` ayrı paketler
    ve çerçeveyi `peerDependency` olarak alıyor. Svelte, Angular ve düz
    HTML için sarmalayıcı bile gerekmiyor: `<kalem-editor>` tarayıcının
    kendi bileşen modeli.
  </Card>
  <Card title="Küçük" icon="rocket">
    Yukarıdaki rozetler ölçülen değerler (min+gzip), hedef değil.
    Bütçeler CI'da zorlanıyor; aşım = build kırmızı.
  </Card>
  <Card title="Modüler" icon="setting">
    Sadece göstermek için `@kalem/viewer`; düzenlemek için
    `@kalem/editor`; Word benzeri arayüz için `@kalem/ui`. Ödemediğiniz
    şeyi indirmezsiniz.
  </Card>
</CardGrid>

## Beş satırda

<Tabs syncKey="cerceve">
  <TabItem label="Vanilla">

```ts
import { Editor } from '@kalem/editor';
import { mountUi } from '@kalem/ui';

const editor = new Editor(document.getElementById('app')!, {
  value: '# Merhaba',
  lang: 'tr',
  label: 'Belge',
  onChange: (markdown) => console.log(markdown),
});
mountUi(editor);
```

  </TabItem>
  <TabItem label="React">

```tsx
import { KalemEditor } from '@kalem/react';

<KalemEditor
  defaultValue="# Merhaba"
  lang="tr"
  label="Belge"
  onChange={(markdown) => console.log(markdown)}
/>
```

  </TabItem>
  <TabItem label="Vue">

```vue
<script setup lang="ts">
import { KalemEditor } from '@kalem/vue';
import { ref } from 'vue';
const metin = ref('# Merhaba');
</script>

<template>
  <KalemEditor v-model="metin" lang="tr" label="Belge" />
</template>
```

  </TabItem>

## Karşılaştırma

| | Kalem | Tiptap | BlockNote | Editor.js |
|---|---|---|---|---|
| Markdown birinci sınıf | ✅ | ❌ HTML odaklı | ❌ JSON | ❌ JSON |
| Framework bağımsız | ✅ | ✅ | ❌ React zorunlu | ✅ |
| Runtime bağımlılığı | **0** | ~10 paket | ~15 paket | birkaç |
| Editör + arayüz (min+gzip) | **35,0 kB** | ~90–120 kB | ~150 kB+ | ~30 kB + eklentiler |
| Sürükle-bırak blok | ✅ | Eklenti | ✅ | ✅ |
| Kayıpsız gidiş-dönüş | ✅ | Kısmi | ❌ | ❌ |

<Aside>
Kalem'in sayısı `size-limit` ile ölçülüyor ve her CI koşusunda yeniden
doğrulanıyor. Rakip değerleri yaklaşıktır (min+gzip) ve bağımsız
ölçülmemiştir.
</Aside>

<Aside type="caution" title="Henüz npm'de değil">
Kütüphane yazıldı ve çalışıyor — bu sayfadaki editör onun kendisi. İlk

açık işler için [iş listesine](https://github.com/yusufkocak1/kalem/blob/main/docs/01-is-listesi.md)
bakın.
</Aside>
