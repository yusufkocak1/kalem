## Neden Kalem?

Yapay zekâ araçlarının çıktı formatı fiilen Markdown oldu. Ancak yazılım bilmeyen
kullanıcıların Word rahatlığında kullanabileceği bir Markdown editörü yok.
Kalem tam olarak bu boşluğu doldurmak için var.

| | Kalem | Tiptap | BlockNote | Editor.js |
|---|---|---|---|---|
| Markdown birinci sınıf | ✅ | ❌ HTML odaklı | ❌ JSON | ❌ JSON |
| Framework bağımsız | ✅ | ✅ | ❌ React zorunlu | ✅ |
| Runtime bağımlılığı | **0** | ~10 paket | ~15 paket | birkaç |
| Hedef boyut (editör+ui) | **~58 kB** | ~90–120 kB | ~150 kB+ | ~30 kB + eklentiler |
| Sürükle-bırak blok | ✅ | Eklenti | ✅ | ✅ |
| Kayıpsız gidiş-dönüş | ✅ | Kısmi | ❌ | ❌ |

<Aside>
Rakip boyutları yaklaşık değerlerdir (min+gzip) ve kendi ölçümlerimizle doğrulanacaktır.
</Aside>

## Üç satırda

```ts
import { Editor } from '@kalem/editor';
import { toolbar, slashMenu, dragHandle } from '@kalem/ui';

new Editor(el, { value: '# Merhaba', plugins: [toolbar(), slashMenu(), dragHandle()] });
```
